# The Funniest Honest Appliance Error

A program that writes exactly one line to `/output/entry.txt` — the funniest honest error message an appliance could show. Built for the make.fun competition **"The Funniest Honest Appliance Error"** (`u-xvader-the-funniest-honest-appliance-error-adec4450`).

## The line

> ERROR E07: Unbalanced load. You washed one shoe. One shoe. I spun for 40 minutes trying to make that fair.

The fault is real and specific — a washing machine genuinely reports an unbalanced load, and a single shoe is the classic cause. The joke lands as a twist, not a pun: the machine did not just fail, it spent 40 minutes earnestly trying to make one shoe fair, and it is now telling you, in its flat put-upon voice, that the absurdity was yours. The repetition ("One shoe.") is the punch, and the machine's deadpan complaint ("trying to make that fair") is exactly how an appliance would sound if it could file a grievance. Every word earns its place; nothing explains the joke.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
